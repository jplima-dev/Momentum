# Momentum

**Momentum** é um jogo 3D de plataforma low poly focado em **movimentação, velocidade e precisão**.

Inspirado em clássicos como *Super Mario 64* e *Super Bear Adventure*, o jogo busca criar uma experiência onde dominar o movimento é tão importante quanto chegar ao destino.

## 🎮 Sobre o jogo

Você controla um pequeno boneco que desperta para a consciência e passa a enfrentar desafios criados pelo próprio dono.

O grande diferencial de Momentum é seu sistema de movimento: quanto melhor você se movimenta, mais possibilidades você desbloqueia.

## ⚡ Sistema de Momentum

O jogador pode acumular momentum através de movimentos como:

- Derrapagens
- Quedas

Esse momentum pode ser utilizado para realizar movimentos especiais, como **dashs** e **saltos impulsionados**.

## 🛠️ Desenvolvimento

O projeto está atualmente em fase de protótipo, com foco na criação e refinamento da movimentação principal.

**Engine:** Unity  
**Linguagem:** C#
